##🦋 WANDER USA
## Features

- 🌎 Explore national parks by state
- 🔍 Search parks by name
- 🖼️ View park images and descriptions
- ❤️ Add and remove favorite parks
- ⭐ View saved favorite destinations
- 🔗 Visit official National Park Service websites
- 📱 Responsive card-based layout

## Technologies Used

- React
- React Router
- JavaScript
- CSS
- Vite
- National Park Service API
